# ICON GYM 💪

אפליקציית אימון ומעקב אישית – תוכנית A/B, חדר כושר ICON חולון.

## מה יש באפליקציה

- **בחירת יום** – כל ימי השבוע עם התוכנית (A1 / B1 / אירובי / A2 / B2 / מנוחה), היום הנוכחי מודגש.
- **הדגמה מצולמת לכל תרגיל** – צילומים של מתאמן אמיתי בחדר כושר, מתחלפים בלופ בין תנוחת ההתחלה לתנוחת הסיום. לחיצה פותחת הדגמה גדולה, **מפת שרירים** (עיקריים/משניים), דגשי ביצוע וגרף התקדמות.
- **רישום סטים** – משקל וחזרות לכל סט, עמודת "קודם" עם מה שעשית בפעם הקודמת, והשדות מתמלאים אוטומטית מהאימון הקודם.
- **טיימר מנוחה** – מתחיל אוטומטית אחרי כל סט, עם רטט וצליל (±15 שניות / דלג).
- **תזכורת להעלאת משקל** 💡 כשהגעת לטווח החזרות העליון בכל הסטים.
- **סיום אימון** – סיכום משך, סטים, נפח ושיאים חדשים 🏆.
- **היסטוריה** – מפת חום של 14 שבועות, כל אימון ניתן לעריכה או למחיקה.
- **התקדמות** – מפת שרירים שבועית שנדלקת לפי מה שאימנת, סטים שבועיים לפי שריר מול התוכנית, משקל גוף, גרף משקל מקסימלי / 1RM משוער / נפח לכל תרגיל.
- **עריכה מלאה** – הוספה, מחיקה, שינוי סדר ועריכה של תרגילים (שם, סטים, חזרות, משקל, מנוחה, תמונות הדגמה), הגדרות יום, העתקת תרגילים בין ימים, ותרגילים מותאמים אישית.
- **מאגר מלא של 800+ תרגילים** עם תמונות הדגמה, מפת שרירים והוראות ביצוע – חיפוש והוספה ישירות ליום (דורש אינטרנט; מה שנפתח פעם אחת נשמר גם לאופליין).
- **גיבוי ושחזור** לקובץ, עבודה **ללא אינטרנט**, ומסך דולק בזמן אימון.

כל הנתונים נשמרים במכשיר עצמו (ללא שרת וללא חשבון).

## התקנה בטלפון

1. פתח את כתובת האפליקציה (GitHub Pages – ראה למטה).
2. **אייפון:** בספארי ← כפתור השיתוף ⬆️ ← "הוסף למסך הבית".
   **אנדרואיד:** בכרום ← תפריט ⋮ ← "התקנת אפליקציה".
3. האפליקציה תופיע במסך הבית עם אייקון ICON ותיפתח במסך מלא, כמו כל אפליקציה.

## הפעלת האתר (GitHub Pages) – פעם אחת

Settings ← Pages ← Source: **Deploy from a branch** ← בחר את הענף ואת התיקייה `/ (root)` ← Save.
אחרי כדקה האפליקציה זמינה בכתובת `https://yitzhaki173-lab.github.io/GYM/`.

## עדכון גרסה

כל שינוי שנדחף לענף שממנו האתר מתפרסם מגיע לטלפון אוטומטית: בפתיחה הבאה תופיע הודעה
"🎉 גרסה חדשה זמינה – עדכן עכשיו". אפשר גם ללחוץ "בדוק עדכונים" בהגדרות.
ההיסטוריה והמשקלים שלך לא נמחקים בעדכון.

למפתחים – בכל שחרור:
- להעלות את `VERSION` ב־`sw.js` ואת `APP_VERSION` ב־`js/app.js` (אותו מספר).
- אם תוכנית ברירת המחדל השתנתה – להעלות את `PROGRAM_VERSION` ב־`js/program.js`; המשתמש יקבל הצעה לעדכן את התוכנית (ההיסטוריה נשמרת).

## מבנה הקבצים

```
index.html            מעטפת האפליקציה
manifest.webmanifest  הגדרות התקנה (שם, אייקונים, צבעים)
sw.js                 Service Worker – עבודה אופליין ועדכוני גרסה
css/app.css           עיצוב
js/media.js           נגן תמונות ההדגמה ומפת השרירים
js/photos.js          נתוני תמונות ההדגמה (נוצר אוטומטית)
js/musclemap.js       צורות מפת השרירים
img/ex/               תמונות ההדגמה (2 לכל תרגיל)
js/program.js         ספריית התרגילים ותוכנית ברירת המחדל
js/app.js             לוגיקת האפליקציה
icons/                אייקונים
```
